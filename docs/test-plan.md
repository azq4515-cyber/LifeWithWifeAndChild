# 手工回归清单

> 没有单元测试框架（离线拿不到包，且对 Unity 主循环收益极低），所以回归靠这张清单。
> 每条都写清"怎么造条件"和"看到什么算过"。带 🧪 的可以用调试指令直接跳到条件，不必真玩 42 天。

## 0. 五分钟冒烟（先做这个）

前提：一个**已婚 + 房子三级 + 有孩子**的存档（没有孩子就先 `lwwc_baby` 造一个）。

```
# 1) 状态能读到
lwwc_info                 -> 阶段/年龄/今天有没有课/家务状态/家庭箱/开关

# 2) 先把孩子放到学龄，并确认课时探测
lwwc_stage 4              -> 立刻变成学龄
lwwc_schedule Penny       -> 打印她今天的「时间 -> 目的地」，看有没有一个 <== 课堂 的标记
lwwc_classroom            -> 打印课堂里的桌子 / 候选座位 / 最终选中的座位

# 3) 造上课条件（如果今天不是春秋的二/三/五）
lwwc_day 2                -> 改成周二（1/8/15/22 周一，2/9/16/23 周二，3/10/17/24 周三，5/12/19/26 周五）
睡一觉                    -> 第二天 DayStarted 重新算课

# 4) 上课
（等到上课时间，或 lwwc_away true）
lwwc_info                 -> 上课: ArchaeologyHouse 900-1500 座位=(x,y)
进课堂                    -> 孩子应该坐在桌旁、面朝 Penny、不游走

# 5) 收桶（周末 + 阶段 5）
lwwc_stage 5
lwwc_day 6                -> 改成周六
lwwc_chest                -> 放一个家庭箱
lwwc_kegs 3               -> 周围 3 个成熟桶
（等 9 点，或 lwwc_chore）
                          -> 孩子逐个走到桶边、有动作、产物进箱子

# 6) 节日（可选，要等节日当天）
（节日当天进节日现场）      -> 原版自动把孩子放在伴侣旁边；确认现场只有一个孩子
```

任何一步 `lwwc_info` 里出现异常（阶段跳变、位置为空、上课/家务状态与实际不符），就已经是 bug。

## 0.1 指令表

| 指令 | 作用 |
|---|---|
| `lwwc_info` | 阶段/天数/Age/今天有没有课/座位/家务状态/位置、家庭箱、开关 |
| `lwwc_stage <0-6>` | 强制阶段（立刻生效，会重算课时与家务） |
| `lwwc_days <n>` | 设置当前阶段已过天数 |
| `lwwc_away <true\|false>` | 强制送到座位 / 强制回家 |
| `lwwc_event <id>` | 播放阶段场景 |
| `lwwc_flags` | 打印剧情 flag 与待播场景 |
| `lwwc_keg` | 立刻**批量**把成熟桶收进家庭箱（不看动作，测试容器用） |
| `lwwc_chore` | 立刻跑一轮「走过去收桶」家务 |
| `lwwc_chest` | 在脚下生成家庭箱 |
| `lwwc_work` | 立刻结算一次孩子能力 |
| `lwwc_rollback` / `lwwc_reload` | 回退一级 / 重建孩子的资产缓存 |
| `lwwc_schedule <NPC>` | **只读**：打印某 NPC 今天的「时间 → 目的地」 |
| `lwwc_classroom` | **只读**：打印课堂的桌子 / 候选座位 / 最终座位 |

测试场景搭建：

| 指令 | 作用 |
|---|---|
| `lwwc_baby [名字] [female]` | 在农舍生成一个阶段 0 的孩子 |
| `lwwc_hearts <0-14>` | 把配偶好感设为指定心数 |
| `lwwc_day <1-28>` | 改当月日期（周几见 §0 的注释） |
| `lwwc_kegs <n>` | 在周围生成 n 个「已成熟、装着酒」的 Keg |

## 1. 成长（P1）

- [ ] **新档 42 天到成年**：`GrowthSpeed=1` 时连睡 6 觉，`lwwc_info` 阶段 0→6 逐级 +1。
- [ ] **原版节奏被接管**：`daysOld` 不随天数单调增长，只停在 0/13/27/55 四个投影值。
- [ ] **老存档迁移**：孩子已 55+ 天的旧档 → 阶段 3，且只提示一次。
- [ ] **卸 mod 不坏档**：备份 → 移走 mod → 读档 → 装回 → 阶段仍在。

## 2. 上课（v1.1 重点）

- [ ] 🧪 **春秋的二/三/五才上课**：`lwwc_day 2` 后睡觉 → 出门；`lwwc_day 1`（周一）后睡觉 → 留家。
- [ ] 🧪 **夏冬放假**：把季节改到夏/冬（或等）→ 任何一天都留家。
- [ ] **雨天停课**：雨天即使周二也不出门。
- [ ] **雪天照上**：冬天下雪**不**上课（季节规则优先），但春秋的雪天仍上课。
- [ ] **课时跟随她**：`lwwc_schedule Penny` 里课堂那条的时间 = 上课时间；她的下一条 = 下课时间。
- [ ] **她不去就没课**：用别的 mod 或改日程让她不去课堂 → 孩子留家，日志有说明，不硬塞。
- [ ] 🧪 **座位**：上课期间进课堂，孩子应在**桌旁**、面朝 Penny、不动。
- [ ] **走不到座位**：把座位堵住 → 孩子应直接落到座位格，而不是卡在门口。
- [ ] **下课回家**：下课后孩子走回农舍，`lwwc_info` 位置变回 FarmHouse。
- [ ] **上课时说话**：右键孩子 → 台词是 `dialogue.in_class`（"嘘——Penny 老师在讲课"）。
- [ ] **中文名/带空格名可上课**；与村民重名 → 不上课且不抢原版资产。

## 3. 周末收桶（v1.1 重点）

- [ ] 🧪 **有动作**：周六 `lwwc_chore` → 孩子**走到**桶边、播动作、产物进家庭箱，然后走向下一个。
- [ ] **只收农场**：棚屋里的桶一件都不动。
- [ ] **只收成熟**：进度 30% 的桶不收；罐头瓶/压酪机不收。
- [ ] **箱子满**：塞满家庭箱再收 → 停下、HUD 报满、桶里产物一件不少。
- [ ] **没有箱子**：删掉家庭箱 → 开收前提示，不动产物。
- [ ] **玩家离开农场**：孩子走到一半时玩家走开 → 暂停；回去后继续。
- [ ] **上限**：把 `MaxKegsPerDay` 设 2 → 收 2 个就收工。
- [ ] **17:00 收工**：没做完也停，HUD 有提示。
- [ ] **不是周末不收**：周三 `lwwc_chore` 仍可强制跑（调试用），但自然流程只在周六日触发。
- [ ] **阶段 4 不收**：`lwwc_stage 4` → 周末什么都不做。

## 4. 节日（原版行为，本 mod 不干预）

- [ ] **孩子在场且只有一个**：节日当天现场，孩子站在伴侣旁边，**不能出现两个**（v1.1.0 的 bug）。
- [ ] **不排课**：节日当天即使是春秋的二/三/五，也**不上课**。
- [ ] **不干活**：节日当天即使周六日，**不收桶**。
- [ ] **存档不丢**：节日中途存档再读档，孩子仍在农舍（不会卡在临时地图）。

## 5. 能力（不变）

- [ ] 🧪 浇水：`lwwc_stage 3` + `lwwc_work` → 若干格变已浇水。
- [ ] 🧪 收畜舍产出：`lwwc_stage 4` + `lwwc_work` → 蛋进背包、地上消失。
- [ ] 🧪 收作物：`lwwc_stage 5` + `lwwc_work` → 产物进背包，再生作物回到第一阶段。
- [ ] 🧪 代售：`lwwc_stage 6` + 出货箱放东西 + `lwwc_work` → 箱子清空、金币增加（约 90%）。
- [ ] 代售不吞垃圾：卖价 0 的物品应留在箱子里。
- [ ] `EnableChildWork=false` → 到点什么都不发生。

## 6. 伴侣联动（阶段场景，不变）

- [ ] **每级一段场景**；伴侣在家时由她开第一句。
- [ ] **场景不打断事件**：节日/事件/菜单中进阶 → 排队等玩家空闲。
- [ ] **上学选择**：`first_school` 后弹选择框；选"再等等" → 当天不上课。
- [ ] **梦想分支**：`dream` 后两个选项分别让孩子之后说 `.dream` / `.rebel`。
- [ ] 🧪 `lwwc_event adulthood` 能直接播。

## 7. 兼容 / 边界

- [ ] **多人模式**：联机存档 → Alert 提示、成长/上课/收桶停用，不报错。
- [ ] **与 CP 共存**：无报错，资产编辑不互相覆盖。
- [ ] **与小孩类 mod 冲突**：装上 → Alert 并禁用成长。
- [ ] **中英切换**：切英文后所有 HUD/对话/配置项都变英文。
- [ ] **config 坏值**：`GrowthSpeed=0/999` → 不崩，按 1/60 处理。
- [ ] **控制台无 Error**：整轮回归后 `[LWWC]` 不应有 Error 行。

## 8. 已自动化的部分

纯逻辑有可执行断言（反射调用编译产物）：

- `StageTable.SyntheticDaysOld` / `FromVanillaDaysOld` / `Abilities`
- `StageExtensions.GoesToSchool`（阶段 4/5 为真，6 为假）
- `Timetable.IsClassroom`（课堂候选地点判定）
- `NameKey.IsUsable`（中文 / 空格 / 空 / 反斜杠 / `..`）

重跑方式：临时 harness 工程反射加载 `LifeWithWifeAndChild.dll`（不入库）。
